## Sobre mim

Sou desenvolvedor com foco em **Java, JavaScript, bancos de dados e soluções para o ecossistema Fusion Platform**. Meu portfólio reúne aplicações de negócio, ferramentas para desenvolvedores, integrações e documentação técnica.

Gosto de aproximar tecnologia e necessidade de negócio: de regras de autorização e APIs a ferramentas que ajudam a investigar logs e trabalhar com processos BPM.

- **Backend e dados:** aplicações Java, APIs, persistência e regras de negócio.
- **Automação e produtividade:** extensões de navegador e recursos para desenvolvimento e diagnóstico no Fusion.
- **Conhecimento compartilhado:** documentação técnica, guias e exemplos de integração.
- **Em evolução:** estudos em React e Next.js, ampliando a atuação no frontend.

### 01 · Fusion DEV Tool

### 02 · Contas a Pagar

![Tecnologia](https://img.shields.io/badge/Spring%20Boot-6DB33F?logo=springboot&logoColor=white&style=flat-square) ![Foco do projeto](https://img.shields.io/badge/Backend%20Java-1E40AF?style=flat-square)

**Backend para um domínio financeiro, desenvolvido como desafio técnico.**

Projeto Java com Spring Boot, persistência com Spring Data, segurança com Spring Security, documentação Swagger e estrutura com JUnit. Inclui instruções de execução com Docker e coleção Postman.

**O que demonstra:** organização de uma API de negócio e uso do ecossistema Spring, com recursos para execução e exploração dos endpoints.

`Java 11` `Spring Boot` `Spring Security` `JUnit` `Docker`

### 03 · Controle de Procedimentos Médicos

![Tecnologia](https://img.shields.io/badge/Hibernate-59666C?logo=hibernate&logoColor=white&style=flat-square) ![Foco do projeto](https://img.shields.io/badge/Regras%20de%20negocio-1E40AF?style=flat-square)

**Regras de autorização aplicadas ao contexto de um plano de saúde.**

Sistema que verifica critérios de idade e sexo para autorizar procedimentos, negando os que não estão previstos nas regras. Utiliza JPA e Hibernate para persistência em MySQL, com interface web e requisições AJAX.

**O que demonstra:** tradução de regras de negócio em software, modelagem de dados e integração entre interface e backend.

`Java` `JPA / Hibernate` `MySQL` `WildFly` `JavaScript`
